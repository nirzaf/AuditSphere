GL CSV v1 profile

One file describes one reporting period, optional reporting book, entity and functional currency. Every journal must balance; all account and dimension codes must already exist in the published client chart. Exact values are validated on the server without currency conversion or rounding.

UTF-8 CSV, up to 10,000,000 bytes, 5,000 rows and 1,000 journals. Larger sources use the existing approved chunk importer. XLSX is not supported by this GL profile.

Required and optional columns

Required: PeriodCode,Entity,Currency,JournalId,LineId,DocumentNumber,PostingDate,SourceSystem,SourceUser,AccountCode,Debit,Credit,OriginalCurrency,OriginalAmount,FunctionalAmount

Optional: BookCode,DocumentDate,ServiceDate,ReversalReference,IsManual,IsYearEnd,PartyIdentifier,Branch,CostCentre,Department,Project,IntercompanyCounterparty

Repeat journal metadata on every line. Use ISO dates, true/false flags and decimal strings with at most six decimal places. Mixed metadata, unknown columns, duplicate lines and unbalanced journals are refused.
